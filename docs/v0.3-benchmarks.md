# v0.3 Benchmark Report

Measured on June 13, 2026 with a release build on Linux x86_64.

The deterministic dataset contains 10,000 structured JSONL rows with monotonic
timestamps, three log levels, and paths sharing long prefixes.

## Results

| Encoder               |   Bytes |  Ratio | Encode MiB/s | Decode MiB/s |
| --------------------- | ------: | -----: | -----------: | -----------: |
| CMP2 explicit codecs  | 741,773 | 0.9443 |       53.987 |       62.306 |
| CMP3 automatic codecs |  23,866 | 0.0304 |       25.660 |      144.737 |
| gzip -9               |  40,074 | 0.0510 | not measured | not measured |

CMP3 is 40.5% smaller than gzip for this representative structured-log
dataset. This is not a universal claim; random or already-compressed values may
select stored representations and can compress worse than gzip.

## Reproduction

```sh
scripts/generate_v03_benchmark.sh 10000 /tmp/compact-v03-bench.jsonl
cargo run --release -p compact-cli -- bench /tmp/compact-v03-bench.jsonl \
  --schema schemas/v03_auto.yml --format v3
gzip -9 -c /tmp/compact-v03-bench.jsonl | wc -c
```

The CMP2 comparison used one 10,000-row block with `delta_varint_u64`,
`dictionary`, and `rle` for the corresponding columns.
