# v0.2 Release Notes

v0.2 adds the first streaming block engine for schema-backed JSONL files.

The release target is bounded-memory sequential encode/decode. It keeps the
schema external via `--schema`, preserves byte-identical JSONL roundtrip for the
supported schema types, and stores independent compressed blocks in a `CMP2`
stream.

## Supported Format

- File magic: `CMP2`
- Version: `2`
- Block payload magic: `BLK1`
- Footer index magic: `IDX1`
- Schema: external YAML passed through `--schema`
- Blocks: independently decodable row groups
- Integrity: each block payload is wrapped in a CRC32-verified frame

The `IDX1` footer is written after all block frames. It stores block index,
encoded offset, row count, raw size, compressed size, and checksum for each
block. Decode remains sequential and stops cleanly when it reaches the footer.

## Supported Schema Types

Supported type and codec pairs remain:

- `u64` + `delta_varint_u64`
- `string` + `dictionary`
- `string` + `rle`

## CLI

Encode with default block limits:

```sh
compact encode input.jsonl output.cmp --schema schema.yml
```

Encode with explicit block limits:

```sh
compact encode input.jsonl output.cmp --schema schema.yml --block-rows 10000
compact encode input.jsonl output.cmp --schema schema.yml --block-bytes 8388608
```

Decode:

```sh
compact decode output.cmp roundtrip.jsonl --schema schema.yml
```

Inspect:

```sh
compact inspect output.cmp
```

Benchmark:

```sh
compact bench input.jsonl --schema schema.yml --block-rows 10000
```

## What Is Done

- Streaming writer and reader for schema-backed JSONL.
- Configurable row and byte block limits.
- Incremental flush by row count and raw byte count.
- Sequential decode without full-file buffering in CLI schema mode.
- Persisted `IDX1` footer index.
- `compact inspect` reports stream format, block count, footer index presence,
  total rows, total raw bytes, total compressed bytes, and per-block metadata.
- `compact bench` reports streaming throughput, block count, rows, ratio,
  encode/decode timing, and MiB/s.
- CLI integration coverage for encode, decode, inspect, bench, block sizing,
  invalid block options, and generated 10,000-row multi-block roundtrip.
- Corruption tests for truncated frames, checksum mismatch, and later-block
  corruption isolation.

## Known Limitations

- No embedded schema.
- No row iterator API yet; decode exposes block-level JSONL internally and CLI
  writes sequentially.
- No column-level stream inspect beyond the existing column-block payload
  metadata.
- No random seek footer pointer yet; the footer index is persisted, but inspect
  currently validates it by scanning the stream.
- Manual 10 GB validation is still recommended before tagging the release.
- No async I/O or parallel block compression.
- No nullable columns, nested JSON, arrays, or schema evolution.
- FFI and Go binding still target the older one-shot JSONL path.

## Release Validation

Automated validation:

```sh
cargo test -p compact-core
cargo test -p compact-cli
cargo check --workspace
```

Manual large-file validation target:

```sh
compact encode generated-10gb.jsonl generated-10gb.cmp --schema schema.yml --block-rows 10000
compact decode generated-10gb.cmp generated-10gb.out.jsonl --schema schema.yml
compact inspect generated-10gb.cmp
```
