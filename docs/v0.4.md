# v0.4 Queryable Columnar Format

v0.4 adds CMP4, a queryable columnar file format built on the v0.3 column
codecs. Data is written as compressed row groups, and a checked EOF footer index
stores row-group ranges, column ranges, and statistics metadata.

## Implemented

- CMP4 header, footer, EOF trailer, checksum validation, and range validation.
- Multi-row-group JSONL encode/decode in `compact_core::io::v4`.
- Footer-only inspect through `compact_core::io::v4::inspect_footer`.
- Column projection through `decode_jsonl_projected` and `scan_jsonl`.
- Predicate pushdown for `u64` range comparisons and `IS NULL`.
- CLI support for `--format v4` encode, decode, inspect, and bench.
- Fuzz target for CMP4 inspect/decode/projection/scan entry points.

## CLI Examples

```sh
compact encode input.jsonl output.cmp4 --schema schema.yml --format v4 --block-rows 1000
compact inspect output.cmp4
compact decode output.cmp4 projected.jsonl --schema schema.yml --format v4 --project id,service
compact decode output.cmp4 filtered.jsonl --schema schema.yml --format v4 --project id --filter-column id --filter-op ge --filter-value 10
compact bench input.jsonl --schema schema.yml --format v4 --block-rows 1000
```

## Remaining Release Hardening

- Add Criterion query benchmarks for lower-noise latency measurement.
- Run long fuzz sessions for `cmp4_decode`.
- Decide whether CMP4 should support byte-size row group flushing in addition
  to row-count flushing.

These are post-release hardening tasks. The v0.4 release includes working core
APIs, CLI integration, build-level fuzz coverage, and automated roundtrip,
projection, predicate, inspect, and benchmark smoke tests.
