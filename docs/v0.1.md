# v0.1 Release Notes

v0.1 is the first single-file JSONL compression MVP.

It is intended for local/offline encode and decode of schema-backed JSONL files.
It does not include streaming, nullable fields, nested JSON, or adaptive codec
selection yet.

## Supported Input

- JSONL input
- One JSON object per line
- Required fields only
- Schema-defined column order

## Supported Schema Types

```yaml
columns:
  - name: ts
    type: u64
    codec: delta_varint_u64
  - name: level
    type: string
    codec: dictionary
  - name: message
    type: string
    codec: dictionary
```

Supported type and codec pairs:

- `u64` + `delta_varint_u64`
- `string` + `dictionary`
- `string` + `rle`

## CLI

Encode:

```sh
compact encode input.jsonl output.cmp --schema schema.yml
```

Decode:

```sh
compact decode output.cmp roundtrip.jsonl --schema schema.yml
```

Inspect:

```sh
compact inspect output.cmp
```

Benchmark:

```sh
compact bench input.jsonl --schema schema.yml
```

## Integrity

Frames include:

- magic bytes
- version
- codec id
- payload length
- CRC32 payload checksum

Invalid frames return errors instead of panicking.

## Fuzzing

Frame decoder fuzzing is documented in [fuzzing.md](fuzzing.md).

## Known Limitations

- No streaming encode/decode
- No nullable columns
- No nested JSON values
- No arrays or objects as column values
- No adaptive codec selection
- No schema evolution
- Go binding is minimal cgo over the Rust FFI
- Python binding is still documentation-only
