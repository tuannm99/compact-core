# v0.6 Kafka-Style Append Example

This example intentionally does not depend on a Kafka crate. The integration
shape is the important part:

```text
consume records -> append JSONL block stream -> periodically snapshot state
recover after restart -> replay valid prefix -> resume consumption
```

## Append Records

```rust
use std::io::Cursor;

use compact_core::streaming::{BlockOptions, append_jsonl_stream};

fn append_batch(
    existing_segment: &[u8],
    jsonl_batch: &str,
    schema: compact_core::schema::Schema,
) -> compact_core::Result<Vec<u8>> {
    append_jsonl_stream(
        existing_segment,
        Cursor::new(jsonl_batch),
        schema,
        BlockOptions {
            max_rows_per_block: 10_000,
            max_uncompressed_bytes_per_block: 8 * 1024 * 1024,
        },
    )
}
```

## Recover On Restart

```rust
use compact_core::streaming::recover_append_stream;

fn recover(segment: &[u8]) -> compact_core::Result<u64> {
    let recovery = recover_append_stream(segment)?;

    // Truncate or ignore bytes after this offset.
    Ok(recovery.valid_len)
}
```

## Replay Committed Records

```rust
use compact_core::streaming::replay_jsonl_append_stream;

fn replay(
    segment: &[u8],
    schema: compact_core::schema::Schema,
) -> compact_core::Result<Vec<u8>> {
    replay_jsonl_append_stream(segment, Vec::new(), schema)
}
```

## Save Checkpoint State

```rust
use compact_core::streaming::{decode_snapshot, encode_snapshot};

fn save_checkpoint(offset: u64, state: &[u8]) -> compact_core::Result<Vec<u8>> {
    encode_snapshot(offset, state)
}

fn restore_checkpoint(snapshot: &[u8]) -> compact_core::Result<(u64, Vec<u8>)> {
    let snapshot = decode_snapshot(snapshot)?;

    Ok((snapshot.checkpoint_id, snapshot.state))
}
```

## Operational Rule

Commit external offsets only after the append stream write succeeds. On restart,
recover the append stream first, restore the latest checkpoint, then replay from
the recovered valid prefix.
