# v0.3.0-alpha.3 Release Notes

This pre-release publishes the completed CMP3 format foundation, numeric bit
packing, boolean bitmap compression, and nullable boolean/u64 columns.

It is a development checkpoint, not the final v0.3 release. The stable
`v0.3.0` tag remains blocked on column statistics, prefix strings, adaptive
codec selection, CLI integration, fuzzing, and release benchmarks.

## Implemented

- `CMP3` file header and versioned column metadata.
- One-shot, independently checksummed `RGB3` row group.
- External YAML schema validation.
- Boolean value bitmap codec.
- Shared validity bitmap for nullable columns.
- Missing nullable fields decode as explicit JSON null.
- Numeric `bitpack`, `delta_bitpack`, `delta_varint_u64`, and `stored` codecs.
- Bit widths from 0 through 64.
- Nullable `u64` columns.
- Mixed boolean/u64 JSONL roundtrip in schema order.
- Strict metadata, payload length, padding, count, checksum, and trailing-byte
  validation.
- Existing CMP2 regression coverage remains passing.

## Public Module Layout

```text
compact_core::format::v3
compact_core::io::v3
compact_core::codecs::v3::boolean
compact_core::codecs::v3::numeric
compact_core::primitives::bitmap
```

## Limitations

- CMP3 currently writes one row group and has no footer index.
- CMP3 is exposed through the core API, not the CLI or FFI.
- String columns are not implemented for CMP3.
- `codec: auto` is parsed but not executable.
- No column statistics or CMP3 inspect output.
- No CMP3 fuzz target or final compression benchmark report.
- This pre-release does not satisfy the complete v0.3 Definition of Done.
