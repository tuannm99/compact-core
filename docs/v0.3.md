# v0.3 Release Notes

v0.3 adds the stable CMP3 advanced column format for one-shot structured JSONL
compression.

## Features

- Numeric bit packing, delta bit packing, delta-varint, and stored fallback.
- Boolean value bitmaps and shared validity bitmaps.
- Nullable `u64`, boolean, and string columns.
- Prefix, dictionary, RLE, and stored string codecs.
- Deterministic `codec: auto` selection using complete encoded candidate size.
- Persisted selected codec and type-specific column statistics.
- Metadata-only CMP3 inspect output.
- CLI encode, decode, inspect, and benchmark support through `--format v3`.
- Strict checksum, length, count, padding, UTF-8, and trailing-byte validation.
- CMP3 decoder fuzz target.

## Schema Example

```yaml
columns:
  - name: ts
    type: u64
    codec: auto
  - name: active
    type: bool
    codec: auto
    nullable: true
  - name: path
    type: string
    codec: auto
```

## CLI

```sh
compact encode input.jsonl output.cmp3 --schema schema.yml --format v3
compact decode output.cmp3 output.jsonl --schema schema.yml --format v3
compact inspect output.cmp3
compact bench input.jsonl --schema schema.yml --format v3
```

## Limitations

- CMP3 currently writes one independently checksummed row group per file.
- The schema remains external.
- CMP3 is not yet exposed through the C FFI.
- Cross-block dictionary reuse is intentionally deferred; dictionaries are
  block-local to preserve independent decoding.

Benchmark results are documented in [v0.3-benchmarks.md](v0.3-benchmarks.md).
