# v0.7 FFI and Multi-Language SDK

v0.7 exposes compact-core through a safer cross-language surface. The release
focuses on a documented C ABI, explicit Rust-owned buffer management, and usable
Go, Python, and Node SDK entry points.

## What Is Included

- C ABI additions in `compact-ffi`
  - `compact_version`
  - `compact_status_message`
  - `CompactBuffer`
  - `compact_buffer_free`
  - `compact_encode_bytes_rle`
  - `compact_decode_bytes_rle`
- Go SDK
  - File encode/decode wrappers.
  - Version wrapper.
  - In-memory RLE byte encode/decode wrappers.
  - Unit tests.
- Python SDK
  - Standard-library `ctypes` wrapper.
  - Version wrapper.
  - In-memory RLE byte encode/decode wrappers.
  - File encode/decode wrappers.
  - Unit tests.
- Node SDK
  - Dependency-free CLI-backed wrapper.
  - Version wrapper.
  - In-memory RLE byte encode/decode wrappers.
  - File encode/decode wrappers.
  - Unit tests.
- Cross-language smoke script:
  - `scripts/cross_language_smoke.sh`
- ABI documentation:
  - `docs/ffi.md`

## Memory Ownership

Rust-owned byte buffers returned through the C ABI must be freed with
`compact_buffer_free`. Language bindings copy Rust-owned bytes into
runtime-owned memory before freeing the Rust buffer.

Static strings returned by `compact_version` and `compact_status_message` must
not be freed.

## Validation

The release was validated with:

- Rust workspace tests.
- Rust clippy with warnings denied.
- Go binding tests.
- Python binding tests.
- Node binding tests.
- Cross-language smoke script.

## Limitations

- Node currently shells out to the `compact` CLI instead of using a native addon.
- Python uses `ctypes`; no wheel packaging exists yet.
- Release artifacts are documented and buildable locally, but automated package
  publishing is not implemented yet.
